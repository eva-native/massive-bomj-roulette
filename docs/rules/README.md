# Правила MBR

Эффекты, бонусы и дроп-дебаффы ивента ЛБР. Это основной источник правил: все изменения вносятся сюда, и код плагинов пишется по этим файлам.

| Файл | Что внутри | Сколько |
|---|---|---|
| [effects.md](effects.md) | Эффекты (э) | 27 |
| [bonuses.md](bonuses.md) | Бонусы (б) | 10 |
| [drop-debuffs.md](drop-debuffs.md) | Дроп-дебаффы (д) | 11 |

## Как это работает

- **Эффект** выпадает на колесе эффектов вместе с игрой и действует на эту игру. Некоторые эффекты действуют дольше: например, «Ни шагу назад» — 3 игры.
- **Бонус** лежит у игрока в кармане, пока игрок не потратит его на игру или на крутку.
- **Дроп-дебафф** выпадает, когда игрок дропает игру, и действует на его **следующую** игру. Очков не даёт.
- **«Одноразовое»** значит «один раз на игрока».
- **Веса колеса** пока у всех предметов равны 1.

## Подсчёт очков

Так очки считает сервер (`server/internal/domain/scoring.go`).

**База** = часы HLTB + очки за рейтинг + очки за год. Чем ниже рейтинг и чем старше игра, тем больше очков.

| Рейтинг | Очки | | Год | Очки |
|---|---|---|---|---|
| ≥ 90 | 1 | | ≥ 2024 | 1 |
| 81–89 | 2 | | 2020–2023 | 2 |
| 76–80 | 3 | | 2016–2019 | 3 |
| 71–75 | 4 | | 2010–2015 | 4 |
| 61–70 | 5 | | 2006–2009 | 5 |
| 51–60 | 6 | | 2001–2005 | 7 |
| 45–50 | 7 | | ≤ 2000 | 10 |
| < 45 | 10 | | | |

Пример: GTA San Andreas — 30 ч HLTB, рейтинг 87, 2004 год → 30 + 2 + 7 = **39**.

**Прохождение:**
- база;
- **скорость**: часы HLTB минус твоё время, с округлением (бывает отрицательной);
- **рекорд**: +1 за самое быстрое прохождение этой игры;
- очки эффектов и бонусов.

**Дроп:** −50% базы, округление к нулю (−39 / 2 = −19). «Парашют» отменяет штраф.

> [!NOTE]
> Каждый предмет станет плагином на Lua: `server/plugins/<вид>/<id>.lua`. `id` указан у каждого предмета.

## Не уточнено

- Когда игрок получает бонус: выпадает ли он на отдельной крутке?
- Фиксированные эффекты (ОПАААА +4 и т.п.) начисляются при прохождении или сразу, когда выпали?
- «Одолжи игру у друга»: выбывает ли игра из колеса друга?
- «Рождённый в Убежище»: действует ли на дроп-дебаффы?
- «Плот Армор» + «Самодостаточный»: снимает ли «Плот Армор» запрет на бонусы?
- «Голосование за Путина»: «предмет» — это только бонус?
- «Смута» и «Земский собор»: часы HLTB, рейтинг и год для подсчёта базы.
