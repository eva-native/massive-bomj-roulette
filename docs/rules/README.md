# Правила MBR

Эффекты, бонусы и дроп-дебаффы ивента ЛБР. Это основной источник правил: все изменения вносятся сюда, и код плагинов пишется по этим файлам.

| Файл | Что внутри | Сколько |
|---|---|---|
| [effects.md](effects.md) | Эффекты (э) | 27 |
| [bonuses.md](bonuses.md) | Бонусы (б) | 10 |
| [drop-debuffs.md](drop-debuffs.md) | Дроп-дебаффы (д) | 11 |

## Колёса

| Колесо | Что на нём |
|---|---|
| **Колесо эффектов и бонусов** | Все эффекты и бонусы вместе |
| **Колесо дроп-дебаффов** | Дроп-дебаффы |
| **Колесо игр** | Игры, которые игрок добавил на ивент, кроме тех, что он уже прошёл |
| **Киноколесо** | Фильмы, которые добавили участники ивента. Крутится только по эффекту «Бабина» |

## Ход игрока

Колёса крутятся в таком порядке:

1. **Колесо эффектов и бонусов или колесо дроп-дебаффов:**
   - в начале ивента у игрока **3 крутки** колеса эффектов и бонусов;
   - если игрок прошёл предыдущую игру, он крутит колесо эффектов и бонусов. Число круток зависит от часов HLTB пройденной игры;
   - если игрок дропнул предыдущую игру, он крутит колесо дроп-дебаффов, всегда **один раз**.
2. **Колесо игр.** Некоторые эффекты меняют эту крутку, например «ГЕРАЛЬТ ДВЕ КРУТКИ» или «Внезапный ДЭБ».
3. **Киноколесо**, если на шаге 1 выпала «Бабина».

## Как это работает

- **Эффект** выпадает до крутки колеса игр и действует на игру, которая выпадет следом. На одну игру может выпасть несколько эффектов. Некоторые эффекты действуют дольше: например, «Ни шагу назад» — 3 игры.
- **Бонус** кладётся в карман и лежит там, пока игрок не потратит его на игру или на крутку.
- **Дроп-дебафф** действует на игру, которая выпадет следом. Очков не даёт.
- **Пройденная игра** больше не выпадает тому, кто её прошёл. Так же и с фильмами: просмотренный фильм больше не выпадает тому, кто его посмотрел. Вернуть пройденные игры в колесо может «Сделка с пиксельным дьяволом».
- **«Одноразовое»** значит «один раз на игрока».
- **Веса** пока у всех предметов равны 1.

## Подсчёт очков

Так очки считает сервер (`server/internal/domain/scoring.go`).

**База** = часы HLTB + очки за рейтинг + очки за год. Чем ниже рейтинг и чем старше игра, тем больше очков.

| Рейтинг | Очки | | Год | Очки |
|---|---|---|---|---|
| ≥ 90 | 1 | | ≥ 2024 | 1 |
| 81–89 | 2 | | 2020–2023 | 2 |
| 76–80 | 3 | | 2016–2019 | 3 |
| 71–75 | 4 | | 2010–2015 | 4 |
| 61–70 | 5 | | 2006–2009 | 5 |
| 51–60 | 6 | | 2001–2005 | 7 |
| 45–50 | 7 | | ≤ 2000 | 10 |
| < 45 | 10 | | | |

Пример: GTA San Andreas — 30 ч HLTB, рейтинг 87, 2004 год → 30 + 2 + 7 = **39**.

**Прохождение:**
- база;
- **скорость**: часы HLTB минус твоё время, с округлением (бывает отрицательной);
- **рекорд**: +1 за самое быстрое прохождение этой игры;
- очки эффектов и бонусов.

**Дроп:** −50% базы, округление к нулю (−39 / 2 = −19). «Парашют» отменяет штраф.

> [!NOTE]
> Каждый предмет станет плагином на Lua: `server/plugins/<вид>/<id>.lua`. `id` указан у каждого предмета.

## Не уточнено

- Сколько круток колеса эффектов и бонусов даёт пройденная игра в зависимости от её часов HLTB?
- Если игру дропнули, учитываются ли очки её фиксированных эффектов (ОПАААА +4 и т.п.)?
- Брошенная игра тоже больше не выпадает тому, кто её дропнул?
- «Плот Армор» + «Самодостаточный»: снимает ли «Плот Армор» запрет на бонусы?
