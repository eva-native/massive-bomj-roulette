## F8 — что сделано и почему

- **P8.1:** участник открывает собственный ход из списка ивентов и после вступления. Общая ссылка на ивент остаётся удобной зрителям.
- **P8.2:** данные своей доски из общего кэша дают точку «ждёт вас»; запущенный таймер даёт ⏱. Подписка на сохранённое состояние секундомера обновляет индикатор в текущем окне и по событию `storage` из другого окна, не запускает второй таймер. Маркеры относятся только к текущему ивенту и незавершённой игре.
- **P8.3:** внешняя ссылка на правила у заголовка; затухание появляется только у скрытого края ряда вкладок. При открытии раздела и изменении ширины активная вкладка видна, при ручной прокрутке ряд не возвращается принудительно к ней.
- **P8.4:** на своей доске активен «Мой ход», на чужой — «Таблица», включая `aria-current`.
- **P8.5:** карточка таблицы называется «Очки».
- **P8.6:** общий вход в шапке вторичен по отношению к «Войти, чтобы участвовать».
- **P8.7:** заголовок вкладки браузера содержит раздел, название ивента, а для судьи — размер очереди. При выходе из ивента прежний заголовок восстанавливается.

Тесты проверяют маршруты, смену маркеров и заголовков, изоляцию ивентов, работу индикатора секундомера и прокрутку ряда вкладок. Визуальная проверка на 390/1440 px остаётся на ревью: браузерный инструмент в текущем сеансе недоступен.
